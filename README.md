# 🏏 IPL Score & Match Winner Prediction System

A production-ready, full-stack Machine Learning application built using **FastAPI** (Backend) and **React** (Frontend) to predict real-time IPL scores and winning probabilities based on historical match data.

## 🚀 Tech Stack
- **Frontend:** React.js, Tailwind CSS
- **Backend:** FastAPI, Python
- **Database:** PostgreSQL
- **Machine Learning:** Pandas, NumPy, Scikit-Learn, MLflow
- **DevOps:** Docker

## 📊 Key Features
- Predicts 1st innings projected scores after 5, 10, or 15 overs.
- Calculates dynamic winning probability for teams during the run-chase.
- Accounted for venue biases, pitch conditions, and historical head-to-head records.
- Microservices architecture deployed safely using Docker containers.
